MAIN BASE BOAT TEMPLATE INSTRUCTIONS
====================================

To enable village switching from Main Base to Builder Base, you need to capture a screenshot of the boat.

HOW TO CAPTURE THE BOAT:
1. Open Clash of Clans and go to your Main Base (home village)
2. Make sure the boat is visible on screen (it's usually on the right side)
3. Use a screenshot tool to capture just the boat
4. Save the image as "boat.png" in this directory

TIPS:
- The boat should be clearly visible and recognizable
- Crop the image to include just the boat with minimal background
- Use the same resolution/scaling as when you captured other templates
- The template should match the boat's appearance in normal gameplay

Once you add boat.png to this directory, the bot will be able to detect it and switch villages automatically.
